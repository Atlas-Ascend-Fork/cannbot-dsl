## 项目文档

本仓库提供基于 CANNBot-DSL 的 Ascend NPU 复杂算子样例，配套精度测试和开发文档。可先阅读[项目介绍](/zh/guide/project/overview)与[仓库结构](/zh/guide/project/repository)，再按目标选择编程模型、样例参考或 API 文档。

环境安装见[开始使用](/zh/install/)，验证方法见[运行测试](/zh/project/examples/testing)，提交修改前请阅读[参与贡献](/zh/project/community/contributing)。版本变更见[更新日志](https://gitcode.com/cann/cannbot-dsl/blob/master/CHANGELOG.md)，授权条款见[许可证](https://gitcode.com/cann/cannbot-dsl/blob/master/LICENSE)。
