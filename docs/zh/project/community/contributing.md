# 参与贡献

欢迎通过 Issue 和合并请求参与项目建设。提交修改前，请先确认改动范围清晰，并为行为变化补充必要的测试或文档。

## 基本流程

1. Fork 仓库并从最新的目标分支创建开发分支。
2. 完成代码和文档修改。
3. 运行与改动相关的测试及仓库检查。
4. 检查提交中没有构建产物、缓存或本地配置。
5. 创建合并请求，说明问题、修改结果和验证方式。

## 文档修改

修改 `docs/` 后，在该目录运行：

```bash
npm install
npm run build
```

构建成功后再启动生产预览，检查桌面和窄屏下的导航、内容和代码块。

## 提交说明

提交信息应简洁描述实际改动。合并请求说明应包含修改动机、最终行为和验证结果，便于维护者复核。
