当前版本提供项目概览、编程模型、样例导航和首批 API 文档，具体包括：

- 文档站首页和全局导航。
- 项目定位与仓库结构说明。
- 编程模型总览、22 节正文和一个附录，覆盖语言机制、数据与硬件、算子实践和工程化。
- 已有算子样例导航。
- 首批公共 API 文档。
- 测试和贡献流程入口。
- 本地构建及生产预览配置。

文档构建检查用于验证页面生成和站内链接，不代表 API 示例已通过设备运行验证。接口的验证记录应注明 DSL/CANN 版本、硬件型号、测试用例和结果。

后续内容会在来源、版本和示例经过校验后逐步加入。
