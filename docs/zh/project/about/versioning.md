# 文档版本策略

CANNBot-DSL 文档只维护一份源码，同时提供开发预览和商用版本两种构建结果。

## 开发预览

- 来源：`main` 分支。
- 版本标识：`next`。
- 用途：查看最新目录、API 和开发中内容。
- 特性：内容会随提交持续变化，不作为商用资料引用。

## 商用版本

- 来源：冻结的 `release/x.y` 分支或 `vX.Y.Z` Git tag。
- 版本标识：对应的 `vX.Y.Z`。
- 用途：提供可追溯、可复现的固定文档。
- 规则：已发布版本不回写；修复通过新的 patch 版本发布。

## API 路径

API 分类保持仓库现有的 Host、Kernel、AI CPU 体系。版本构建只改变站点基础路径，API 相对路径保持一致：

```text
next/zh/api/host/...
v0.1.0/zh/api/host/...
```

这样开发站点和商用站点可以映射到同一套 API 页面 ID，不需要维护两份文档正文。
