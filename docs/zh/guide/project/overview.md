# 项目介绍

CANNBot-DSL 仓库用于展示面向 Ascend NPU 的复杂算子实现和工程实践。现有内容覆盖注意力、矩阵乘、归一化、点云处理与体素卷积等场景。

## 项目目标

- 提供结构完整、可以阅读和测试的算子样例。
- 沉淀算子开发中的工程组织与验证方法。
- 为社区贡献者提供统一的代码、测试和文档入口。

## 支持范围

仓库当前面向 NPU ARCH 3510，对应 Ascend 950PR 与 Ascend 950DT。各样例的输入约束、运行方式和验证情况以其目录中的 README 为准。

## 文档建设方式

文档内容会分批进入开源仓库。每批内容在合入前都需要完成本地构建、页面预览和链接检查，避免未验证内容直接进入正式站点。
