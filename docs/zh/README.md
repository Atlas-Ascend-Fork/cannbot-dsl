
# 中文文档目录

`docs/zh` 是 CANNBot-DSL 的中文文档根目录。文档按发布用途分为 API 参考、开发指南、安装构建和项目资料四类。

## 目录结构

- [`api/`](api/index.md)：Host、Kernel 和 AI CPU API 参考；社区目录清单见 [`index_hiascend.md`](api/index_hiascend.md)。
- [`guide/`](guide/index.md)：开发指南和编程模型；社区目录清单见 [`index_hiascend.md`](guide/index_hiascend.md)。API 与开发指南的英文版本后续由人工翻译维护。
- [`install/`](install/index.md)：环境准备、安装、构建和预览。
- [`project/`](project/index.md)：项目说明、样例导航和贡献信息。

API 与 Guide 目录中的 `index.md` 只作为目录节点，正文放在同级的独立页面中，便于昇腾社区解析父子节点。
