# 通用接口文档模板

本模板用于编写 CANNBot-DSL 公共接口文档。接口名称、参数和约束必须以公开接口及验证结果为准，不描述内部实现或底层接口调用。

## 产品支持情况

用于说明接口支持的硬件产品范围，产品名称和排列顺序保持统一。支持状态只写“支持”“不支持”或“待确认”，未经验证的产品不得标记为“支持”。

```markdown
- Ascend 950PR/Ascend 950DT：待确认
- Atlas A3 训练系列产品/Atlas A3 推理系列产品：待确认
- Atlas A2 训练系列产品/Atlas A2 推理系列产品：待确认
- Atlas 200I/500 A2 推理产品：待确认
- Atlas 推理系列产品 AI Core：待确认
- Atlas 推理系列产品 Vector Core：待确认
- Atlas 训练系列产品：待确认
```

## 功能说明

直接说明接口完成的操作、输入数据和处理结果，通常控制在一至三句话。数学接口应使用公式或伪代码明确覆盖、累加、广播或转置等行为，不写编译流程和内部调用关系。

```markdown
`api_name` 对输入执行……，并将结果写入……。
```

## 函数原型

准确展示公开接口的参数顺序、关键字参数、类型、默认值和返回类型。类型使用开发者可见的 Python 或 DSL 类型，不使用内部中间表示类型。

```python
def api_name(
    required_arg: PublicType,
    optional_arg: PublicType | None = None,
) -> ReturnType: ...
```

## 参数说明

固定使用“参数、输入/输出、类型、必选、默认值、说明”六列。

- “输入/输出”只使用“输入”“输出”或“输入/输出”；特定模式下会读取原值时，明确写出触发条件。
- “类型”使用公开类型，多个类型使用“或”连接。
- “必选”只使用“是”或“否”，必选参数的默认值写“无”。
- “说明”准确描述参数功能，通常不超过两句话。较长的 shape、dtype、layout、存储位置、对齐及参数组合限制放入[约束说明](#约束说明)。

```markdown
| 参数 | 输入/输出 | 类型 | 必选 | 默认值 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `arg` | 输入 | `Tensor` | 是 | 无 | 指定……。 |
```

无参数接口直接写“无参数”。

## 返回值说明

明确返回内容和公开类型。通过输出参数返回结果时，说明结果写入哪个参数；存在累加或原地更新时，说明原有数据如何变化。

有返回值接口：

```markdown
返回……，类型为……。
```

无返回值接口：

```markdown
无返回值。结果写入 `dst`。
```

## 约束说明

只记录影响接口正确使用的限制。每条约束必须明确说明约束对象、触发条件和具体要求，包括支持值、取值范围、shape、dtype、layout、存储位置、对齐或互斥关系。

- 不使用“仅适用于支持该能力的场景”“需要相应配置”等含糊表述。
- 多个参数存在组合限制时，明确列出合法或非法组合。
- 存在数据依赖时，明确说明发生冲突的访问以及所需的 Channel 或同步关系。
- 不重复功能说明和参数说明已经表达的内容。

```markdown
- `arg` 仅支持……。
- 当……时，……必须……。
```

## 调用示例

首先用一句话说明完整示例实现的功能，然后在接口页中直接编写 Python 代码块。示例必须能够独立执行，并包含必要导入、Kernel 定义、Host 调用、设备同步、结果校验和 `main` 入口。

示例应使用确定性输入，通过断言或 `torch.testing.assert_close` 校验结果，只保留当前接口所需的辅助代码。接口页不重复运行环境和执行命令。

````markdown
以下示例……，并在 Host 侧校验……。

```python
# 在这里编写可独立执行的完整示例
```
````

### 预期结果

只展示程序稳定输出。物理核编号等运行时动态值使用占位符，不填写固定数值。

```text
api_name example passed
...
```
