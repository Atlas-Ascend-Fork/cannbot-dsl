# Array 简介

## 产品支持情况

- Ascend 950PR&950DT系列产品：支持

## 功能说明

Array 用于保存固定数量的 Kernel 运行时标量。通过整数下标读取或写入，可以保存跨循环迭代使用的索引、偏移和标记。

## 原型定义

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `length` | `int` | 数组元素数量。 |
| `element_type` | 类型描述 | 数组元素的存储类型。 |

## 使用方式

假设 `a` 为 Array 对象，`i` 为下标，`value` 为待写入值：

- `a[i]`：读取第 `i` 个元素。
- `a[i] = value`：写入第 `i` 个元素。
- `len(a)`：读取元素数量。

`i` 可为 Python 整数或运行时整数，必须满足 `0 ≤ i < a.length`。写入值可以是符合目标类型要求的 Python 常量，或与 Array 元素类型相同的运行时标量；运行时标量类型不一致时，须先显式转换为 Array 的元素类型。多个变量引用同一 Array 时，共享其内容。

## 约束说明

- 无初始化值时，元素须先写入再读取。
- 运行时下标不自动检查越界。
- 不支持 `for value in a`，须通过 `a[i]` 访问元素，其中 `i` 为整数下标。
- 在 Kernel 或其调用的 jit 中使用；VF/SIMT 内不能创建或访问 Array，可在区域外读取标量后传入。
- Array 的分配作用域须覆盖全部访问位置。
