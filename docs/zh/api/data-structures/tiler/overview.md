# Tile / Tiler 简介

## 产品支持情况

- Ascend 950PR&950DT系列产品：支持

## 功能说明

Tile和Tiler用于描述切块大小。可以用一个整数表示一维块长，用元组或列表组合多个维度，也可以嵌套组合，例如`((16, 32), 8)`。

## 使用方式

| 形式 | 示例 | 含义 |
| --- | --- | --- |
| 固定切块大小 | `(16, 32)` | 直接给出各维切块长度。 |
| 运行时确定的切块大小 | `(m, 32)` | `m`是执行时确定的整数，例如从输入Tensor形状中读取的维度长度。 |
| 带对齐要求的切块规格 | `cannbotdsl.make_tiler((16, 32), alignment=16)` | 记录切块结构及可选对齐条件。 |
