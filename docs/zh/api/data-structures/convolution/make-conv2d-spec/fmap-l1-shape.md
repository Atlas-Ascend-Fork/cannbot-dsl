# Conv2dSpec.fmap_l1_shape

## 产品支持情况

- Ascend 950PR&950DT系列产品：支持

## 功能说明

根据输出空间位置块大小和输入通道块大小，计算一个特征图块所需的 L1 缓冲区容量，供分配存储使用。返回的是元素个数构成的形状，不是字节数。

计算同时满足以下两种用途的容量，取所需元素个数的较大值：

- 保存输入特征图：预留当前块大小下的最大输入窗口，窗口保留完整输入宽度。
- 暂存零数据：当后续窗口展开遇到全部落在补零区域的输出块时，提供所需的零数据空间。

记输入高、宽为 $H_i$、$W_i$，卷积核高、宽为 $K_h$、$K_w$，步长为 $S_h$、$S_w$，膨胀率为 $D_h$、$D_w$，左右填充宽度为 $P_l$、$P_r$。$B_M$、$B_C$ 对应 `tile=(BM, BC)`。

先计算有效卷积核大小及输出宽度：

$$
K_h^{\mathrm{eff}} = D_h(K_h-1)+1,\qquad
K_w^{\mathrm{eff}} = D_w(K_w-1)+1
$$

$$
W_o = \left\lfloor\frac{W_i+P_l+P_r-K_w^{\mathrm{eff}}}{S_w}\right\rfloor+1
$$

为兼顾输出块在一行中不同的起始位置，按以下保守上界预留输入窗口：

$$
R_{\max} = \left\lfloor\frac{B_M+W_o-2}{W_o}\right\rfloor+1
$$

$$
H_{\max} = \min\left(H_i,\;(R_{\max}-1)S_h+K_h^{\mathrm{eff}}\right)
$$

其中，$R_{\max}$ 为预留的输出行数上界，$H_{\max}$ 为最大输入窗口高度；$\lfloor\cdot\rfloor$ 表示向下取整。窗口保留完整输入宽度 $W_i$。

特征图容量 $E_f$、零数据容量 $E_z$ 及最终容量 $E$ 均以元素个数计：

$$
E_f = B_C H_{\max} W_i,\qquad
E_z = B_M K_h K_w B_C
$$

$$
E = \max(E_f,E_z)
$$

返回形状为 `(E,)`。若每个元素占 $b$ 字节，则按此形状分配缓冲区的数据容量为 $E b$ 字节；本接口支持的 `float16`、`bfloat16` 均有 $b=2$。容量不随某个尾块的有效长度缩小，也不等于某次搬运的实际数据量。

例如输入为 `(1, 16, 4, 4)`，卷积核为 1×1，步长和膨胀率均为 `(1, 1)`，无填充，`tile=(16, 16)`：

$$
W_o=4,\quad R_{\max}=\left\lfloor\frac{16+4-2}{4}\right\rfloor+1=5,\quad
H_{\max}=\min(4,5)=4
$$

$$
E_f=16\times4\times4=256,\quad E_z=16\times1\times1\times16=256,\quad E=256
$$

因此返回 `(256,)`，按此形状分配 `float16` 缓冲区时数据容量为 512B。

## 函数原型

```python
spec.fmap_l1_shape(*, tile: Sequence[int]) -> tuple[int]
```

## 参数说明

| 参数 | 输入/输出 | 说明 |
| --- | --- | --- |
| tile | 输入 | 指定一次卷积计算要处理多少个输出位置、多少个输入通道，格式为 `(BM, BC)`：BM 为每块处理的输出通道数，BC 为每块处理的输入通道数（分组内）。<br>必填，无默认值，须以关键字传入。<br>支持包含 2 个编译期整数的 tuple/list。BM 为正的 16 的整数倍且不超过 65535；BC 为 16 或 32；Kh×Kw×BC 不超过 32767，最大输入窗口高度乘输入宽度不超过 65535。 |

## 返回值说明

返回一元组 `(元素个数,)`，容量可容纳当前块大小下最大的有效输入窗口，并兼顾全填充窗口所需的临时零数据。实际分配的元素类型须与 `spec.dtype` 一致。

## 约束说明

分配的容量须与后续卷积搬运使用的 spec 和块大小匹配。
