# Conv2dSpec.tile_count

## 产品支持情况

- Ascend 950PR&950DT系列产品：支持

## 功能说明

根据每块大小，计算输出空间位置、输出通道和输入通道三个方向的块数，用于组织卷积循环。输出、输入通道均在单个分组内切分。

## 函数原型

```python
spec.tile_count(tile: Sequence[int]) -> tuple[int, int, int]
```

## 参数说明

| 参数 | 输入/输出 | 说明 |
| --- | --- | --- |
| tile | 输入 | 每块大小 `(BM, BN, BC)`，分别表示输出空间位置数、输出通道数和输入通道数。输出空间位置指将输出高、宽按行展开后的位置。须为包含 3 个整数的 tuple/list；BM、BN 须为编译期正整数，均为 16 的整数倍且不超过 65535；BC 须为 16 或 32，且 Kh×Kw×BC 不超过 32767。最大输入窗口高度乘输入宽度不得超过 65535。必填，无默认值。 |

## 返回值说明

返回 `(M块数, 输出通道块数, 输入通道块数)`，分别为输出高×输出宽除以 BM、每组输出通道数除以 BN、每组输入通道数除以 BC 后向上取整的结果。

## 约束说明

本方法使用的块大小须与后续 [spec.tile](tile.md) 的块大小一致。
