# Conv2dSpec.tile_count

## 产品支持情况

- Ascend 950PR&950DT系列产品：支持

## 功能说明

根据每块大小，计算输出空间位置、输出通道和输入通道三个方向的块数，用于组织卷积循环。输出、输入通道均在单个分组内切分。

## 函数原型

```python
spec.tile_count(tile: Sequence[int]) -> tuple[int, int, int]
```

## 参数说明

| 参数 | 输入/输出 | 说明 |
| --- | --- | --- |
| tile | 输入 | 每块大小 `(BM, BN, BC)`：BM 为输出高、宽按行展开后构成空间位置，BN 为输出通道数，BC 为输入通道数；输入、输出通道均在当前分组内切分。<br>必填，无默认值。支持包含 3 个编译期整数的 Tuple/List。BM、BN 须为正的 16 的整数倍且不超过 65535；BC 为 16 或 32；Kh×Kw×BC 不超过 32767。最大输入窗口高度乘输入宽度不得超过 65535。 |

## 返回值说明

返回 `(空间位置切分块数, 输出维度切分块数, 输入维度切分块数)`，分别为输出高 × 输出宽 / BM、每组输出维度数 / BN、Ceil ( 每组输入维度数 / BC ) 。

## 约束说明

本方法使用的块大小须与后续 [spec.tile](tile.md) 的块大小一致。

## 调用示例

可将返回的三个块数分别用作输出空间位置、输出通道和输入通道方向的循环上限，并用循环编号调用 [Conv2dSpec.tile](tile.md) 取得当前切块。
