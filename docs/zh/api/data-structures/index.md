# 数据结构

本目录介绍算子代码中传递和组织数据的对象。`Tensor` 表示可访问的数据视图，`Layout`、`Shape`、`Stride` 描述访问方式，`Tiler` 描述切块规格，`Buffer`、`Storage` 和 `RingBuffer` 管理片上存储。
