# 计算

本目录介绍 Kernel 中的计算接口。页面按计算类型组织；Host、Kernel 和 AI CPU 是调用上下文，具体页面会在接口说明中标明适用位置。

## 目录

| 类别 | 内容 |
| --- | --- |
| [张量计算](./tensor/index.md) | 张量切片、坐标转换和常用数学辅助操作 |
| [标量计算](./scalar/index.md) | 标量位运算、转换和旁路访存 |
| [矢量计算](./vector/index.md) | Reg 矢量计算、寄存器搬入搬出和掩码操作 |
| [矩阵计算](./matrix/index.md) | Cube 矩阵乘加、分形格式和计算模式 |
| [原子计算](./atomic/index.md) | GM 上的原子读改写操作 |

SIMT 接口暂不在本轮展开，后续以专题形式补充；本目录保留现有公开页面的完整索引。
