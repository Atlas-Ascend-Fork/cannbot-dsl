# CANNBot-DSL 0.8.0

<div class="release-meta"><time datetime="2026-10-29">PyPI上架日期：2026-10-29</time><span>软件包：<code>cannbot-dsl</code></span><span>对比版本：0.7.1</span></div>

## 摘要

本版本统一数据搬运的配置方式，引入RingBuffer和标量Array，扩展Tensor形状变换与编译缓存能力，并完善动态形状搬运和标量计算。

## 新增与改进

### 数据搬运与数据结构

- 使用`copy_options`集中配置`mem_copy`的搬运选项，支持通过`convert`、`relu`、`pad`和`cat`描述搬运中的类型转换、激活、填充和拼接。
- 引入RingBuffer，通过`next_write()`和`next_read()`依次选择可复用的存储槽位，替换原有Channel接口；根据数据访问推导所需的同步。
- 提供固定长度的标量Array，支持按下标读写，替换`DelayLine`和`DelayLineGroup`。
- 扩展Tensor的`reshape`、`flatten`、`unflatten`等形状变换操作，支持在保持原数据存储的基础上描述搬运所需的视图。
- 新增GroupSync，支持多个生产者和消费者通过`acquire`、`commit`、`wait`、`release`进行核间协作（仅`abi3` wheel）。

### 编译与调试

- 新增`aot.compile_cache`，缓存相同配置下的编译结果，供Python调用及Native算子打包复用。
- 改进动态Tensor参数传递，减少静态形状和跨度信息的重复传递。
- 统一条件分支、循环等控制流中的自动同步处理。
- 支持在编译时保留行号信息，辅助定位生成代码中的问题。

## 问题修复

- 修复GM→L1格式转换搬运对合法N轴、K轴尾块的限制，支持相应的动态尾块长度。
- 修复`bfloat16`类型`vmadd`的代码生成问题。
- 修复标量表达式的类型处理与生成代码不一致的问题。
- 修复从源码目录运行时，编译缓存不能正确查找已安装发行包信息的问题。

## 接口变更

- Channel及其创建接口替换为`RingBuffer`、`make_ring_buffer`。
- `make_copy_engine`及独立搬运配置替换为`copy_options`。
- `DelayLine`、`DelayLineGroup`替换为`Array`。
- AI CPU参数声明中的`GmIn`、`GmOut`更名为`gm_in`、`gm_out`。
- 移除`Storage`、`Tensor.bare`及`next_read`、`next_write`的`bare`参数，直接使用Tensor（仅`abi3` wheel）。
- 移除`logical_format`、`physical_shape`、`physical_stride`属性及`extent`接口；维度长度通过`shape`读取，物理形状和跨度通过`physical_layout.shape`、`physical_layout.stride`读取（仅`abi3` wheel）。

## 安装与下载

本版本提供Linux `x86_64`、`aarch64`架构的wheel包，覆盖CPython 3.10、3.11、3.12、3.13。

```bash
python -m pip install cannbot-dsl==0.8.0
```

| 文件名中的标识 | Python支持 | glibc最低版本 |

| `cp310`、`cp311`、`cp312`，且不含`abi3` | 对应的CPython 3.10、3.11、3.12 | 2.28 |
| `abi3` | CPython 3.10、3.11、3.12、3.13 | 2.17 |
