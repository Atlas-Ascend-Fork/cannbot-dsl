# CANNBot-DSL 0.7.1

<div class="release-meta"><time datetime="2026-10-15">PyPI上架日期：2026-10-15</time><span>软件包：<code>cannbot-dsl</code></span><span>对比版本：0.7.0</span></div>

## 摘要

本版本修复AI CPU编译环境选择和片上存储容量查询问题，改善无设备环境下的编译支持。

## 问题修复

### AI CPU编译

- 统一使用`ASCEND_HOME_PATH`指定的CANN安装目录，避免编译工具和头文件来自不同的CANN安装。
- 修复在`x86_64` Host上编译AI CPU算子时的目标架构选择，使用面向设备的AArch64工具链。
- 从所选工具链读取版本和系统路径，取消对固定工具链版本及用户安装目录的依赖。

### 片上存储容量查询

- 修复无设备环境下`get_mem_size`返回`0`的问题：对已支持的目标架构，按编译目标查询UB、L1、L0A、L0B、L0C等片上存储容量。
- 容量查询采用编译目标架构的信息，避免编译目标与Host检测到的设备不一致时使用错误的容量。

## 环境要求

AI CPU编译不再自动查找CANN安装目录，须通过`ASCEND_HOME_PATH`指定。

## 安装与下载

本版本提供Linux `x86_64`、`aarch64`架构的wheel包，适用于CPython 3.10、3.11、3.12，要求glibc 2.28及以上。

```bash
python -m pip install cannbot-dsl==0.7.1
```
