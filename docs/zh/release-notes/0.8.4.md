# CANNBot-DSL 0.8.4

<div class="release-meta"><time datetime="2026-11-18">源码版本更新日期：2026-11-18</time><span>软件包：<code>cannbot-dsl</code></span><span>对比版本：0.8.3</span></div>

## 摘要

本版本支持运行时队列长度归并，默认构建并打包原生通信模块，扩展数据搬运与矢量访存的地址自更新能力，并完善异常诊断。

## 新增与改进

### 排序与矢量计算

- `vmrgsort4`的`lengths`支持设备端整数标量，可与编译期整数混用。运行时长度和队列容量须满足接口约束。
- 扩展`post_update`地址自更新支持，覆盖`vload_unalign`以及广播加载、展开加载和打包存储。

### 数据搬运与核间协作

- 二维UB→L1搬运支持运行时确定内轴宽度。
- 固定tile的GM NZ视图支持动态K维和物理跨度。
- DSL wheel默认包含原生通信模块和运行时库，构建时无需单独开启通信选项。
- 支持显式AIC与单个AIV之间的双向同步。

### 调试与构建

- 增强AIC异常诊断，支持在异常发生时保存输入Tensor，并改进Python源码定位。
- OpKit支持缓存Bisheng设备编译和Native Host编译结果，并行调度AOT IR构建。

## 问题修复

- 修复L0C→UB随路量化为INT8时因UB行距未对齐导致的错数，编译时校验目标物理行距。
- 修复MX矩阵乘对`fp4x2_e1m2`的数据类型校验。
- 修复`mul_cast`将无符号整型结果错误推断为有符号整型的问题。
- 修复部分SIMT数学函数、标量原子操作和类型转换的类型校验及映射。
- 完善无效L0C读取和UnitFlag等待的诊断，并拦截单行GEMV使用分形L0A的调用。

## 安装与下载

本版本提供Linux `x86_64`、`aarch64`架构的wheel包，适用于CPython 3.10、3.11、3.12、3.13。

安装指定版本：

```bash
python -m pip install cannbot-dsl==0.8.4
```
