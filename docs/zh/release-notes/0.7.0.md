# CANNBot-DSL 0.7.0

## 摘要

本版本提供从Python编写算子、编译到设备执行的开发能力，覆盖Host入口、Kernel定义、Tensor操作、数据搬运、矩阵与矢量计算，以及AI CPU算子开发。

## 主要功能

### 语言与编译

- 使用`@host`定义Host入口、`@kernel`定义核函数、`@jit`定义辅助函数，支持从Host函数启动Kernel。
- 支持条件判断、循环，以及通过`const_expr`和`range_constexpr`按编译时已知的条件和范围生成代码。
- 提供`compile`提前编译接口，通过`TensorSpec`、`Dim`、`TensorListSpec`和`StructSpec`描述输入参数，支持动态维度、Tensor列表和结构体参数。
- 提供`aot.export`、`aot.build`和`aot.register_directory`，用于导出、打包和加载Native算子。

### 数据与计算

- 提供Tensor、布局和切片操作，支持ND及NZ、ZN格式的数据访问。
- 提供片上缓冲区分配与复用能力，根据Tensor的数据访问自动处理受支持场景的同步。
- 提供`mem_copy`数据搬运接口，以及矩阵乘、卷积、矢量和标量计算接口；支持SIMD与SIMT编程。
- 提供分布式数据传输及同步接口，用于多卡算子开发。

### AI CPU与调试

- 支持通过`@aicpu_kernel`定义AI CPU函数，在Host上验证计算结果，并编译后在设备上启动。
- 提供`print`、`dump_tensor`和`dump_reg`调试能力，以及性能分析所需的Kernel和Tensor信息上报。
- 提供`get_platform_info`和`get_mem_size`，查询平台信息和片上存储容量。

## 安装与下载

本版本提供Linux `x86_64`、`aarch64`架构的wheel包，适用于CPython 3.10、3.11、3.12，要求glibc 2.28及以上。

```bash
python -m pip install cannbot-dsl==0.7.0
```
