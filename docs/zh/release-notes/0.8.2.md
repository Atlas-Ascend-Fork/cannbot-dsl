# CANNBot-DSL 0.8.2

<div class="release-meta"><time datetime="2026-11-06">PyPI上架日期：2026-11-06</time><span>软件包：<code>cannbot-dsl</code></span><span>对比版本：0.8.0（abi3 wheel）</span></div>

## 摘要

本版本完善Tensor视图和搬运操作，新增卷积数据搬运与设备函数导出，扩展核间协作能力，并增强源码定位和性能分析。部分接口名称、参数和属性有所调整。

## 新增与改进

### Tensor与数据搬运

- 统一GM与片上Tensor的视图操作，使用`from_tensor`创建基于已有Tensor的视图，支持通过`Tensor.expand`、`Tensor.pad`描述扩展和填充。
- 将搬运中的类型转换和ReLU操作统一为`Tensor.convert`、`Tensor.relu`方法；`convert`支持量化偏移、负值缩放系数和输出截断等控制。
- 支持使用`x[start:stop:step]`描述带步长的切片。
- 新增`load3d`及配套参数类型，用于卷积特征图的数据搬运。
- 扩展L0C输出转换，支持FP32累加结果按通道配置缩放系数。

### 核间协作与通信

- 扩展`GroupSync`核间协作能力，新增非阻塞申请和等待。
- 对SSBUF中的Tensor，根据实际访问推导执行核及同步，取消显式选择`vec`、`cube`视图的要求。
- 提供`cannbotdsl.comm`通信接口，支持按rank建立连接，区分UB_MEM与URMA传输，并支持在UB中构造URMA写入和通知请求。

### 编译与调试

- 新增`export_device`，导出可供外部AscendC工程调用的设备函数源码及参数说明文件。
- 新增`compile.with_options(sk_configs=...)`，支持配置SuperKernel编译选项；`@kernel`新增`schedmode`配置。
- 为API参数检查补充Python调用位置，编译错误可定位到对应源码。
- 新增`print_time_stamp`，记录设备时间戳、代码位置标记和执行核信息。
- 支持按算子及Tensor的形状、数据类型分类保存生成的AscendC源码。

## 问题修复

- 修复批量GM→L1格式转换搬运时，源和目标批次跨度不同导致的地址计算问题。
- 修复批量GM→L1搬运对转置视图的处理。
- 修复MX计算中动态缩放数据跨度的处理。
- 修复性能分析结果中算子名称与类型的显示问题。
- 完善VF内未初始化数据读取和Tensor超出有效作用域的检查。

## 接口变更

- `reinterpret`改为`from_tensor`，`broadcast_to`改为`Tensor.expand`；独立的`permute`、`reshape`、`flatten`、`unflatten`函数改为同名Tensor方法。
- 删除`strided_slice`，改用`x[start:stop:step]`；`pad`、`Tensor.pad_to`改为`Tensor.pad`，`Tensor.with_tail_fill`改用`copy_options`的`pad_val`参数。
- 删除`Tensor.view`的`size`参数，改用`view(*shape)`；删除`size`接口，通过`shape`读取各维长度。
- 删除Tensor和RingBuffer的`physical_format`以及RingBuffer的`layout_map_kind`，通过`data_format`查看存储格式，通过`layout`、`physical_layout`查看布局。
- 删除SSBUF Tensor的`vec`、`cube`属性，由框架根据访问推导执行核。
- 删除`target_version`，编译期条件使用`const_expr`。
- 删除`cube_busy_wait`和`try_wait`；`PIPE`仅保留`S`、`V`、`M`、`MTE1`、`MTE2`、`MTE3`、`ALL`和`FIXPIPE`。
- `cannbotdsl.distributed`通信接口调整为`cannbotdsl.comm`，调用代码需适配新的接口。

python -m pip install cannbot-dsl==0.8.2
