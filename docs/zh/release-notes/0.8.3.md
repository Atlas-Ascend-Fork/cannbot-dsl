# CANNBot-DSL 0.8.3

<div class="release-meta"><time datetime="2026-11-12">PyPI上架日期：2026-11-12</time><span>软件包：<code>cannbot-dsl</code></span><span>对比版本：0.8.2</span></div>

## 摘要

本版本新增排序、归并和矩阵转置接口，扩展64位整数数据搬运及原子写入能力，并增强运行时打印、异常诊断和输入Tensor保存能力。

## 新增与改进

### 排序与矩阵转置

新增以下接口：

| 接口 | 功能 |
| --- | --- |
| `vbitsort` | 对每组32个分数分别执行降序排序，并保留对应索引，支持`float16`和`float32`分数。 |
| `vmrgsort4` | 将2、3或4路已按降序排列的记录归并为有序结果。 |
| `vtranspose` | 对16×16的`int16`或`uint16`矩阵执行转置并写入目标Tensor。 |

### 数据搬运与矢量计算

- 完善`mem_copy`的`int64`、`uint64`搬运支持，支持GM→UB、UB→GM和UB→UB方向。
- 为`copy_options`新增`atomic`参数，在支持原子写入的UB→GM、L0C→GM路径中选择加法、最小值或最大值归约。原有`atomic_add=True`写法继续可用。
- 为`vrelu`新增`int64`支持。
- 改进`mem_copy`的参数检查，在编译时报告不支持的存储位置、布局或控制参数组合，并定位到调用处。

### 调试与问题定位

- 为`print`新增Host和Kernel运行时格式化打印。
- 新增AIC/AIV异常诊断，记录异常Kernel及其参数并生成诊断报告；编译时启用行号信息后，可定位到生成的AscendC源码行。
- 新增输入Tensor保存功能，支持在算子调用前保存指定Tensor的数值、形状、数据类型和格式，用于输入检查与问题复现。该功能默认关闭，开启后会增加设备到CPU的数据复制和磁盘写入开销。

## 问题修复

- 修复搬运带偏移的UB Tensor视图时，源或目标地址计算错误的问题。
- 修复`vreduce_sum_datablock`的结果类型选择：`int16`输入返回`int32`结果，`uint16`输入返回`uint32`结果。
- 修复`vgather_reg`的类型检查，按源元素位宽要求对应的无符号索引类型，并对不支持的组合给出错误提示。

## 安装与下载

本版本提供Linux `x86_64`、`aarch64`架构的wheel包，适用于CPython 3.10、3.11、3.12、3.13。

安装指定版本：

```bash
python -m pip install cannbot-dsl==0.8.3
```
