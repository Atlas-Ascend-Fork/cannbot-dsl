
# Installation and getting started

## Quick start

1. Prepare the CANN toolkit, the Ascend 950 operator package, Python, and Node.js.
2. Install the CANNBot-DSL dependencies described by the repository README.
3. Choose a sample from the [sample navigation](../../../samples/) and follow its README.
4. Run the sample test and compare the result with the documented validation method.
