# Documentation scope

The documentation site is released in stages.

## Current release

This release provides the project overview, programming model, sample navigation, and the first API pages. It also includes the site home page, repository guidance, test and contribution entry points, and local build and preview configuration.

The documentation build checks page generation and site links. It does not mean that API examples have been validated on a device. Validation records should state the DSL and CANN versions, hardware model, test case, and result.

Additional content will be added after its source, version, and examples have been reviewed.
